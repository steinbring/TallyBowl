# TallyBowl!

**How you bowled, tonight.**

A planned Flutter app for macOS, iPadOS, and Android. Capture or import a scoreboard photo, review locally recognized frame results, track your alleys and bowling balls, and share a branded session recap.

Recognition runs entirely on the device. The first release uses local storage with backup/export and OpenStreetMap maps through `flutter_map`.

See the [project roadmap](docs/ROADMAP.md) for confirmed scope, delivery milestones, technical risks, and acceptance criteria.

Status: product roadmap drafted; the Flutter application has not been scaffolded yet.
