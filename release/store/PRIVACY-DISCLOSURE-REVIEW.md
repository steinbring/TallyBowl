# Privacy disclosure review for publication

The live policy at https://tallybowl.jws.app/privacy/ returned HTTPS 200 on
November 13, 2026. The current app also bundles an offline policy in Settings.
Update stale metadata docs that still call the public URL unavailable.

The journal, identity/aliases, photos used for drafts and recognition stay on the
device unless the user exports or shares them. There is no app account, ads,
automatic cloud sync or developer-operated analytics. Do not classify local-only
journal content as data uploaded to the developer. Recognition on Apple uses
Vision; Android uses bundled ML Kit, whose diagnostics include device/app and
processing metadata. Apple disclosures must not copy Android SDK declarations.

Map tiles and submitted alley searches contact OSM/Photon providers, which see
IP/request metadata and queries. Assess retention and the stores' definitions
before final declarations. User-controlled exports/backup services have separate
handling. A no-login app does not need an invented account-deletion website;
retain accurate local deletion and backup instructions.

Review and publish Apple privacy answers and Google Data safety before public
submission. The dedicated App Privacy URL editor did not enable Save, so its
final URL/disclosure state still needs completion. No unverified blanket
no-data-collected declaration was submitted during this task.
